# My Space Booking — Fresh

Fresh clean starter for the My Space Luxury Suite booking system.

## Before upload
Open `index.html` and replace:
- `PASTE_YOUR_SUPABASE_URL_HERE`
- `PASTE_YOUR_SUPABASE_ANON_KEY_HERE`

Use only the Supabase **anon/public** key in the browser. Never put the Supabase service-role key in this file.

This starter expects the database tables already created in the fresh Supabase project:
- profiles
- properties
- bookings
- blocked_dates
